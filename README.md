# Job Vacancy Data: Data Preparation & Exploratory Analysis

Tools: Python, Pandas, Jupyter Notebook

This project explores a dataset of open job vacancies published by Infrabel through the European Union Open Data Portal. It serves as a preliminary step toward a broader web-scraping and job-market analysis project, focusing on building a structured data-analysis pipeline from raw data to insights. Using Python and Pandas, I worked with a raw dataset, cleaned and prepared it, and performed Exploratory Data Analysis (EDA) to identify patterns and characteristics.
# Overview:
Developed an exploratory data analysis and data preprocessing pipeline focusing on public job vacancy datasets (sourced via open-data API principles) to evaluate labor market demand trends across municipalities.
